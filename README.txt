   Existing project report.
3. Output_Screenshots/
   Folder for graph images generated by running the R script.
4. Model_Evaluation_Results.csv
   This file is generated after the script runs successfully.

IMPORTANT DATASET STEP
The original CSV dataset was not available in the files I could package here.
Copy your original file named:
air_quality_health_impact_data.csv
from your Posit Cloud project into this folder before running the R script.
Do not replace it with a different dataset, because the report's results refer to
the original dataset.

HOW TO RUN
1. Put the CSV dataset in the same folder as R_Microproject_Code.R.
2. Open the folder as an RStudio/Posit Cloud project, or upload the script and CSV
   into your Posit Cloud project.
3. Open R_Microproject_Code.R and click Source (or run the full script).
4. The script creates figures in Output_Screenshots and
   Model_Evaluation_Results.csv.
5. Review the generated graphs and confirm the metrics match your report before
   submitting.

NOTE
The report states that the dataset is synthetic. The analysis is for academic
practice only and is not medical evidence or a diagnostic tool.
